# junited-autoglas – Einsatzplanung (Demo)

Quick-Demo einer Web-App für die Einsatzplanung eines junited-AUTOGLAS-Standorts.
Reine statische Seite, nur Beispieldaten, Änderungen bleiben im Browser (localStorage).

- **Chef:** Dashboard mit Ampel, Auslastung pro Mitarbeiter, Zuweisung
- **Mitarbeiter (5):** Kalender, Termine übernehmen/zurückziehen, „Meine Termine“, Erledigt-Haken
- **Zwei-Personen-Regel** je Fahrzeugtyp (Demo-Liste)
- **Demo-Leiste:** Termine neu mischen, Zurücksetzen

Dateien: `site/index.html` (die komplette App), `site/logo.png`.
Veröffentlichung über GitHub Pages (`.github/workflows/pages.yml`).
Hintergrund, Entscheidungen und offene Punkte: siehe [NOTIZEN.md](NOTIZEN.md).
Live: https://aozcorap.github.io/junited-autoglas/
Lokal testen: `site/index.html` im Browser öffnen.
